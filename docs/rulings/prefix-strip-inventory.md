# The `miso-engine-` prefix strip: the classification inventory

**Class**: a naming ruling plus the line-by-line evidence for it, on the same model as issue #215's
`docs/rulings/de-versioning-inventory.md`. This file is the audit surface for the rename that drops
the `miso-engine-` prefix from every workspace crate's package name, directory, and Rust crate
identifier (`[lib]`/`[[bin]]` name).

## The rule

*A crate's package name, directory, and Rust identifier are decoration, not contract identity,* and
so are born unprefixed. `crates/miso-engine-session` becomes `crates/session` (package `session`,
`[lib] name = "session"`). The **one** deliberate exception in the mapping is
`crates/miso-engine-core`, which becomes `crates/engine` (package `engine`, `[lib] name = "engine"`)
-- **not** `core`, and not `engine-core`. A package literally named `core` silently shadows Rust's
sysroot `core` crate for every dependent: it compiles (that is the trap), then fails downstream with
no diagnostic that explains itself (`error[E0433]: cannot find 'mem' in 'core'` at the *call site*,
not the declaration), and collapses the prelude and the `derive` attribute outright in a `no_std`
crate. Neither `::core::mem` nor `extern crate core as x; x::mem` escapes it -- cargo's
`--extern core=<path>` overrides the sysroot crate of that name unconditionally. `engine` has none of
that risk, reads as the crate it is (the render engine's foundation), and keeps the rule that every
other package obeys: `[lib] name` equals the package name with hyphens turned to underscores, with no
per-crate exception carved into the policy gate.

**Never rewritten, by the same standard the de-versioning ruling used for `V1`/`_v1`:** a spelling
that is itself visible across a boundary a consumer outside this crate's own source depends on --a
wire tag, an exported C-ABI/wasm symbol, a gate-pinned or sealed spelling-- is contract identity, not
a crate name, and this rename does not touch it. Concretely:

- `miso_engine_v1_*` -- 14 exported C-ABI symbols (`fixtures/capi-qualification/v1/EXPECTED_SYMBOLS.txt`,
  `crates/capi/include/miso_engine_v1.h`). These are explicit `#[no_mangle]` names in source, not
  crate-derived -- renaming `miso-engine-capi` to `capi` does not move them, and this was verified
  live (`bash scripts/check-capi-abi.sh` and `bash scripts/test-capi-abi.sh`, both green after the
  rename, and a byte-diff of `EXPECTED_SYMBOLS.txt` against `origin/main` showing no change).
- `miso_engine_web_v1_*` -- 28 wasm exports.
- `miso_engine_effect_*_v1` -- the C-ABI effect-descriptor family. One instance,
  `miso_engine_effect_contract_v1`, collides textually with the mapped stem `effect_contract` (it is
  `miso_engine_effect_contract` + `_v1`); the rewrite tooling excludes it by exact match, verified by
  grep before and after.
- `miso_engine_graph_v1` -- the dot-graph digraph identifier (`crates/graph-compiler/src/canonical.rs`,
  `fixtures/graph/v1/direct-route.dot`). Same collision shape against the mapped stem `graph`,
  excluded the same way.
- `miso_flac_decoder_v1_*` -- the FLAC sidecar's own C-ABI family. Does not share a prefix with any
  mapped crate name (`miso_flac_decoder_v1_*`, not `miso_engine_flac_decoder_v1_*`), so it was never
  at risk from the rewrite tooling; verified anyway.

`MISO_ENGINE_*` environment-variable names (191 distinct spellings across `scripts/`, e.g.
`MISO_ENGINE_BENCH_PROFILE`, `MISO_ENGINE_CAPI_LIBRARY`) are a separate, uppercase namespace, not a
casing of any crate identifier, and were not touched: the rewrite tooling matches the 48 old crate
spellings **case-sensitively**, and none of them is uppercase.

## Method

The rewrite is driven by the explicit 48-entry mapping in the table below, applied as a single
case-sensitive, longest-alternative-first regular expression over every tracked file's content
(`git ls-files`, binary/undecodable files skipped, four trees excluded -- see Scope below). Each of
the two frozen-ABI collisions above is excluded by a negative-lookahead on the specific trailing
`_v1` spelling, not by touching the pattern for `effect_contract`/`graph` themselves (which remain
correct everywhere else they occur). `Cargo.lock` and `fuzz/Cargo.lock` are excluded from the text
rewrite and regenerated by `cargo update`/`cargo build` instead, because their content is
resolver-computed, not literal text to find-and-replace.

A blanket regex over `miso[-_]engine[-_]` was **not** used: `\b` is broken for the hyphen form
(`sed -E 's/\bmiso-engine-graph\b/X/'` turns `miso-engine-graph-compiler` into `X-compiler`), and a
prefix strip is not safe near a `lib`-artifact filename either -- `libmiso_engine_capi.a` has no word
boundary between `lib` and `miso_engine_capi`, so `\b`-anchored matching would silently skip it.

## Scope: which trees were rewritten

Renames land in `crates/`, `hosts/`, `tools/`, `sidecars/`, `scripts/`, `docs/`, `sdk/`, `fuzz/`,
`.github/workflows/**` and `AGENTS.md`.

Four trees are **frozen** and were not rewritten, because their content is a record rather than an
implementation (unchanged from the de-versioning ruling's list):

| tree | why frozen |
|---|---|
| `.github/ISSUE_SPECS/**` | the accepted specification of each issue as it was accepted, carrying sha256 pins of the artifacts of its day; 21 filenames in this tree carry a crate name (`084-audit-miso-engine-core.md` ... `107-audit-miso-engine-session.md`) and are left exactly as accepted. |
| `artifacts/**` | sealed measurement evidence. |
| `dsp-research/**` | sealed listening evidence and archived research. |
| `fixtures/**` | fixture **bytes** are digest identity. |

**One carve-out this ruling needs that the de-versioning ruling did not:** that ruling proved
`git diff --name-only origin/main -- fixtures artifacts dsp-research .github | wc -l` is `0`. A crate
rename **cannot** hold that for `.github/` as a whole, because `.github/workflows/**` is live
configuration (`-p` flags, `fuzz.yml`'s `paths:` filters, `browser-qualification.yml`'s
`working-directory`/`cache-dependency-path`) and must be rewritten along with the code it gates. The
frozen half of `.github/` is `.github/ISSUE_SPECS/**` only; the proof grep below states this
explicitly so it is not read as a regression.

`docs/rulings/de-versioning-inventory.md` is **not** a frozen tree (it is a live ruling), but it is a
historical record of a *previous* rename, and its own proof greps depend on its crate-name mentions
staying byte-identical to what they were when written. It is treated as frozen in practice for this
rename, the same call the de-versioning ruling made for the fixture comment it left alone.

### The C-ABI qualification evidence ledger

`fixtures/capi-qualification/v1/AUTHORITIES.sha256` is a sealed 26-row ledger of `<sha256>  <path>`
pinning the exact source tree the accepted C-ABI V1 qualification was taken from; 17 of its rows are
`crates/miso-engine-*`/`tools/miso-engine-*` paths. This is **not** a blocker and was **not** edited:
`scripts/check-capi-qualification-v1.sh:37-46` documents in its own comment that the
`sha256sum --check --strict` self-seal was already retired as permanently red by waves 1-4, before
this rename, pending issue #26 re-running the qualification -- eleven paths in that ledger had
already drifted from the live tree prior to this change. What the gate still enforces is shape-only
(`LC_ALL=C sort -c -k2,2`, exactly 26 lines, a row-shape regex), and editing the paths would break
that sort order and fail loudly for no benefit, since the self-seal that would make a re-pin
meaningful is already gone. The file is left byte-identical.

## Digests that moved

The package name is part of the built artifact's bytes (panic-location strings bake in the in-repo
relative source path, which includes the crate's own directory name), so any crate whose package or
directory renamed re-pins its build output. Within this repo:

- `sidecars/flac-decoder/decoder-artifact.sha256` and the matching constant in
  `sidecars/flac-decoder/flac-decoder.js` (formerly `miso-engine-flac-decoder.js`/`.sha256`) --
  package-only rename (directory already moved by #305). Re-pinned and reproduced twice to confirm
  determinism; values recorded in the commit that lands the re-pin.
- `hosts/host-web`'s AudioWorklet wasm closure changed (every crate it depends on renamed), so its
  build output is not byte-identical either, though `build-web-audioworklet.sh` does not pin the
  digest in-repo (no `--remap-path-prefix`, no committed `.sha256`) -- only the app's
  `miso-engine-v1.provenance.json` pins it, cross-repo.

**Out of scope for this PR, by design:** the app repo (`misofm/app`) re-vendor of both digests. That
is a separate follow-up after this merges, per the task's scope boundary -- this PR does not touch
`misofm/app`.

## Proof greps

### 1. Frozen trees did not move

```sh

    docs/rulings/de-versioning-inventory.md | wc -l   # -> 0
```

`.github/workflows/**` is *not* in that list -- it is live configuration, not a frozen record (see
Scope above) -- and did change, in exactly the files that gate the rename's own correctness:

```sh
git diff --name-only origin/main -- .github/workflows
#   .github/workflows/browser-qualification.yml
#   .github/workflows/ci.yml
#   .github/workflows/fuzz.yml
```

### 2. No required-check name moved

```sh
for f in .github/workflows/*.yml; do
  diff <(git show origin/main:"$f" | grep -E '^\s*name:') <(grep -E '^\s*name:' "$f")
done   # -> no output: every job/step `name:` line is byte-identical to origin/main
```

### 3. No old spelling survives outside a frozen tree or a deliberately protected one

```sh
git grep -nIE '<the 48-name alternation, longest-first>' -- \
    crates hosts tools sidecars scripts docs sdk fuzz AGENTS.md .github/workflows \
    ':(exclude)docs/rulings/de-versioning-inventory.md' \
    ':(exclude)docs/rulings/prefix-strip-inventory.md'
```

collisions (`miso_engine_effect_contract_v1`, `miso_engine_graph_v1`), the three
