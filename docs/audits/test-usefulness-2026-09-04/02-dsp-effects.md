# Test-usefulness audit: effect-runtime and the ten dependent crates

Shared facts every verdict below leans on:

- **Conformance harness** (`crates/conformance/src/effect.rs`, one generated test per effect via `effect_conformance_test!`, mandated by `scripts/check-effect-contract.sh:22-36`). Per quality × link mode × bypass at quantum 128 it asserts: `descriptor.validation`, `metadata.exact`/`metadata.changed`, allocation/lock/log/io/feature-detection/panic-free `process` under a real counting allocator (`bench_support`, `effect.rs:730-770`), D7 output bounds, snapshot determinism + restore, dual-mono lane isolation, one malformed span (`u32::MAX` index), bypass = dry delayed by declared latency, partition invariance over **{1, 127, 128}** frames for `latency + 256` samples with **no automation** (`:906-916`), 100× determinism, NaN/Inf/subnormal input and sidechain bounds, both resets (`FullToDefaults` == fresh snapshot), and a continuation probe that compares **4 samples at offset 2** (`:1440-1470`) — vacuous for every effect whose latency exceeds 6 samples (compressor 882/960, multiband 960, gate 480, soft-clip 31, limiter). It never binds a bank (`bind_homogeneous_bank`), never arms `reset`/`snapshot`/`restore` (only `process` is inside `armed_process`), and asserts nothing about mono collapse, silent fast paths, ramp laws, observation taps, or oracle numerics.
- **G5** (`tools/wasm-gates/tests/g5_native_corpus.rs`): `g5_native_digests_match_pins` renders every delegated corpus (effect-runtime D1, transient-shaper, delay, multiband, soft-clip, parametric-eq E9, gate-expander, builtins, limiter D90, compressor C1) through the owning crate's `run_case` at all three widths (`tools/wasm-gate-corpus/src/lib.rs:653-700, 1129-1245`) against the owning crate's own pin constants, and `g5_delegated_cases_use_the_owning_crates_pins` asserts those constants are the crate's. `wasm-gates` is a workspace member, so it runs in the debug workspace leg **and** the release leg (`ci.yml:70, :481`). Its finiteness/vacuity checks (`g5_lane_corpus_is_finite`, `g5_no_case_is_vacuously_zero`) skip delegated families (`has_lane_values`, `lib.rs:480`).
- **CI double-run**: every effect crate's tests run in debug (`ci.yml:70`) and again in release (`ci.yml:171-224`); every second saved below is saved twice. `tools/audit {delay,compressor,parametric-eq,gate-expander}` (100,000 blocks, release) covers realtime allocation/syscalls for those four; soft-clip, transient-shaper, true-peak-limiter, multiband have only their own `allocation.rs`.
